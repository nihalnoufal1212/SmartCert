SMARTCERT PROTOTYPE V2 — QUICK START

1. Extract SmartCert_Prototype_V2.zip.
2. Open index.html in Chrome or Edge.
3. Internet access is needed for the PDF library CDN.
4. Click “Load demo data” to try it immediately, or upload a CSV.
5. Choose event/title/theme and click “Generate certificate PDF”.

CSV columns:
name,email,event,award

Required: name
Optional: email,event,award

Features:
- CSV upload and parsing
- Duplicate-name and duplicate-email detection
- Search/filter participants
- Quick-add participant manually
- Live certificate preview and selectable themes
- Preview navigation and click-to-preview table rows
- Export validation report as CSV
- Generate multi-page PDF; invalid/duplicate rows are skipped
- Sample CSV download and demo data

Not implemented:
- Email delivery
- Login/database persistence
- Public online certificate verification
